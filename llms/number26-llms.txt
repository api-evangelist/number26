# Number26 (N26)

> Number26 — trading as N26 (N26 GmbH) — is a German licensed digital bank (BaFin) serving 8M+ customers across 24 European markets. Its only public API surface is the XS2A "Access to Account" interface it is required to expose under EU PSD2, implemented to the Berlin Group NextGenPSD2 1.3.6 standard for licensed third-party providers (AISP/PISP/CBPII). There is no general-purpose public developer API.

## APIs
- [N26 XS2A (Berlin Group PSD2) OpenAPI](https://raw.githubusercontent.com/api-evangelist/number26/refs/heads/main/openapi/number26-xs2a-openapi-original.yml): Consent, account, balance, and transaction endpoints for licensed TPPs. Base URL https://xs2a.tech26.de/v1/berlin-group/v1

## Docs
- [N26 Open Banking / PSD2 TPP documentation](https://github.com/n26/psd2-tpp-docs): Dedicated, fallback, and sandbox interface docs; eIDAS QWAC certificate requirements; Postman collection.
